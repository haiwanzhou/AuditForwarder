Enrollment

主机接入（一键生成客户端配置）

点击生成后会自动下载 client_windows_<主机ID>.yaml，同时该主机以「离线」状态登记到主机管理列表。 将下载的文件复制到新电脑客户端目录的 config/client_windows.yaml（替换原文件），启动客户端后自动注册上线，全程无需修改任何代码。
