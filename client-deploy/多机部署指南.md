# AuditForwarder 多机互联部署指南

## 架构

```
电脑A（服务端）                          电脑B（客户端）
┌─────────────────────┐                 ┌─────────────────────┐
│ auditforwarder-     │   HTTP :8443    │ auditforwarder-     │
│ server.exe          │ ◄──────────────  │ client.exe          │
│  - Web管理台        │   事件批次上报    │  - 采集系统日志     │
│  - 主机注册/心跳    │                 │  - 文件/进程/网络   │
│  - 远控命令下发     │                 │  - 命令/注册表/ETW  │
│  listen 0.0.0.0:8443│                 │  指向服务端IP:8443  │
└─────────────────────┘                 └─────────────────────┘
```

---

## 第一步：服务端机器（电脑A）

### 1.1 确认服务端配置

编辑 `config/server_windows.yaml`，确保：

```yaml
manager:
  enabled: true
  listen: 0.0.0.0:8443          # 0.0.0.0 表示监听所有网卡，允许外部连接
  auth_token: ""                 # 建议设置非空值，两端必须一致
  enrollment_key: ""             # 建议设置非空值，两端必须一致
  use_tls: false                 # 局域网测试可关闭；生产环境建议启用
```

> **安全建议**：跨机器使用时，建议把 `auth_token` 和 `enrollment_key` 设为非空的随机字符串（如 32 位十六进制），客户端配置必须填相同的值。当前为空时跳过鉴权，任何能访问 8443 端口的机器都能上报。

### 1.2 获取服务端机器的局域网 IP

在服务端机器上打开 PowerShell：

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike "127.*" -and $_.IPAddress -notlike "169.254.*" } | Select-Object IPAddress, InterfaceAlias
```

记下这个 IP（例如 `192.168.1.100`），客户端配置需要用到。

### 1.3 放行 Windows 防火墙

以**管理员身份**打开 PowerShell：

```powershell
New-NetFirewallRule -DisplayName "AuditForwarder 8443" -Direction Inbound `
  -Protocol TCP -LocalPort 8443 -Action Allow
```

### 1.4 启动服务端

在项目根目录执行：

```powershell
.\build\auditforwarder-server.exe -c .\config\server_windows.yaml -L info
```

看到 `auditforwarder-server 1.0.0 正在运行` 即启动成功。

## 第二步：客户端机器（电脑B）

### 2.1 拷贝部署包

把服务端机器上的 **`client-deploy`** 整个文件夹拷贝到客户端机器（例如 `D:\AuditForwarderClient\`）。

`client-deploy` 目录结构：

```
client-deploy/
├── auditforwarder-client.exe    # 客户端程序
├── libcrypto-3-x64.dll          # 运行时依赖（6个DLL）
├── libgcc_s_seh-1.dll
├── libssl-3-x64.dll
├── libstdc++-6.dll
├── libwinpthread-1.dll
├── zlib1.dll
├── 启动客户端.bat                 # 双击启动脚本
├── config/
│   ├── rules.yaml                # 检测规则（无需修改）
│   └── client_windows.yaml.template  # 配置模板（需改名为 client_windows.yaml 并填写）
└── data/
    └── client/                   # 日志目录（自动生成）
```

### 2.2 修改客户端配置

把 `config/client_windows.yaml.template` **复制一份**，改名为 `config/client_windows.yaml`，然后编辑以下字段：

```yaml
agent:
  id: "agent-pc-002"              # ← 改成这台机器的唯一标识

transport:
  servers:
    - "http://192.168.1.100:8443/ingest?agent=agent-pc-002"   # ← 服务端IP
  auth_token: ""                   # ← 与服务端一致（空则不鉴权）

remote:
  servers:
    - "http://192.168.1.100:8443"   # ← 服务端IP
  host_id: "agent-pc-002"         # ← 与 agent.id 一致
  enrollment_key: ""               # ← 与服务端一致（空则不鉴权）
```

**必须修改的 3 处**：
1. `agent.id` 和 `remote.host_id`：这台机器的唯一 ID（不能和其他客户端重复）
2. `transport.servers` 中的 IP：服务端机器的局域网 IP
3. `remote.servers` 中的 IP：同上

### 2.3 启动客户端

**方式一（推荐）**：双击 `启动客户端.bat`

**方式二**：在 client-deploy 目录打开 PowerShell：

```powershell
.\auditforwarder-client.exe -c .\config\client_windows.yaml -L info
```

> **注意**：ETW 安全日志采集（`etw_win`）需要管理员权限。如果需要采集 Windows 安全日志，请以**管理员身份**运行。其他采集器（文件/进程/网络/命令/注册表）不需要管理员权限。

## 第三步：验证互联

### 3.1 客户端日志

客户端启动后，查看 `data/client/client.log`，应看到：

```
transport: uploaded batch ... status=200    # 批次上传成功
remote: heartbeat sent ...                    # 心跳发送成功
```

### 3.2 服务端 Web 控制台

在服务端机器（或同一局域网的任意机器）浏览器打开：

```
http://<服务端IP>:8443/
```

登录后进入「主机管理」页面，应能看到客户端主机（`agent-pc-002`）状态为 **在线**，并显示 CPU/内存使用率。

### 3.3 日志与告警

进入「日志与告警」页面，可按采集器类型（file_win / process_win / network_win 等）筛选查看客户端实时上报的系统事件。

## 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 客户端一直不上线 | IP 不通 / 防火墙拦截 / 密钥不一致 | ① 客户端 `ping <服务端IP>` 测试连通 ② 确认服务端防火墙已放行 8443 ③ 核对两端 `auth_token` 和 `enrollment_key` 完全一致 |
| 上传返回 401 unauthorized | auth_token 不匹配 | 客户端 `transport.auth_token` 必须与服务端 `manager.auth_token` 一致；两端都为空则跳过 |
| 注册返回 invalid_enrollment_key | enrollment_key 不匹配 | 客户端 `remote.enrollment_key` 必须与服务端 `manager.enrollment_key` 一致 |
| 端口 8443 连接超时 | 防火墙未放行 / 服务端未启动 | 服务端执行 `Get-NetTCPConnection -LocalPort 8443` 确认监听；检查防火墙规则 |
| ETW 采集器显示 not running | 非管理员权限运行 | 以管理员身份启动客户端；ETW 安全日志需要管理员权限 |
| 客户端闪退 / 找不到 DLL | 运行时 DLL 缺失 | 确保 client-deploy 目录下 6 个 DLL 与 exe 在同一目录 |
| 两台机器不在同一网段 | 网络隔离 | 确保两台机器能互相 ping 通；如需跨网段，需配置路由或端口映射 |

## 扩展：多台客户端

每台客户端机器重复第二步即可，注意：
- 每台客户端的 `agent.id` / `remote.host_id` 必须唯一
- 所有客户端的 `transport.servers` / `remote.servers` 都指向同一个服务端 IP
- 服务端默认 `max_host_count: 1000`，可在 `server_windows.yaml` 中调整
